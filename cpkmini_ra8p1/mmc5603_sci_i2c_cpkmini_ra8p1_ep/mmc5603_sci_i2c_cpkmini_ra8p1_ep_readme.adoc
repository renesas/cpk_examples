在 e^2^ studio 中导入工程，生成并编译，或直接烧录本文件夹下的 mmc5603.hex。打开一个串口调试工具，波特率 2000000，数据位 8bit，停止位 1bit，无奇偶校验。程序烧录后，串口会输出以下信息：

=== 代码

MMC5603 驱动文件位于 src 目录下的 mmc5603.c 和 mmc5603.h。关于 I2C 的操作在 iic.c 和 iic.h 中。在程序入口 hal_entry() 中先进行初始化

[source,c,subs="verbatim,attributes"]
----
IIC_Init();
MMC5603_Init();
----

随后可使用 mmc5603.h 中的 API 读取测量到的磁场数据

[source,c,subs="verbatim,attributes"]
----
MMC5603_GetXYZ(&x, &y, &z);
printf("x: %d, y: %d, z: %d\r\n", x, y, z);
----
