=== 代码

对 OLED 的操作全部在 src/oled 文件夹中。使用时先初始化：

[source,c,subs="verbatim,attributes"]
----
static OLED_Dev s_oled;

void hal_entry(void)
{
	...
	s_oled.write = oledWrite;
    OLED_Init(&s_oled);
	...
}
----

然后可以参照 hal_entry.c 对 OLED 进行写入

[source,c,subs="verbatim,attributes"]
----
void hal_entry(void)
{
	...
	OLED_Fill(&s_oled, 0x00);
	OLED_DrawStr(&s_oled, 0, 0, "CPKHMI-RA8P1", OLED_FONT_8X16);
    OLED_DrawStr(&s_oled, 0, 2, "with", OLED_FONT_8X16);
    OLED_DrawStr(&s_oled, 0, 4, "CPKExp-MINI", OLED_FONT_8X16);
	...
}
----
