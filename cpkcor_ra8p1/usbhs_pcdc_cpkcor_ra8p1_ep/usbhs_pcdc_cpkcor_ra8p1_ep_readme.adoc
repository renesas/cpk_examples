=== 代码

* 此工程还使用 FUSB303B 来设置 USB TypeC 中的 SOURCE 和 SINK，相关例程可以参考 link:../fusb303b_cpkcor_ra8p1_ep/readme.md[fusb303b_cpkcor_ra8p1_ep]

* r_usb_pcdc

使用时先执行初始化

[source,c,subs="verbatim,attributes"]
----
R_USB_Open(g_basic0.p_ctrl, g_basic0.p_cfg);
----

随后在应用循环中处理 USB 事件：
[source,c,subs="verbatim,attributes"]
----
usb_event_info_t usb_event;
usb_status_t usb_status;
R_USB_EventGet(&usb_event, &usb_status);
switch (usb_status) {
    ...
}
----

* 设备描述符

FSP 会生成一个默认的 PCDC 设备描述符模板，位于 `{e2studio工程位置}\ra\fsp\src\r_usb_pcdc\r_usb_pcdc_descriptor.c.template`。此模板默认可直接用于测试使用，但注意若要实际生产使用，需要修改 VID、描述字符串等信息。
