### 支持的开发板 / 开发套件 / 演示板：
- CPKNET-RA8T2 核心板

### 硬件要求：
- 1块Renesas RA8开发板：CPKNET-RA8T2
- 1根USB Type A->Type C或Type-C->Type C线 （支持Type-C 2.0即可）

### 硬件连接：
- 通过 USB Type-C 线连接调试主机和 CPKNET-RA8T2 板上的 USB 调试端口 JDBG。

### 硬件设置注意事项：
- 样例程序的主要运行参数： CPU0 - 600MHz, CPU1 - 不使用, ICLK 200MHz
- 该运行参数是模拟Tj=125摄氏度规格的RA8T2 MCU，不是核心板上RA8T2 MCU可支持的最快运行速度（1G/250M）

  - e2studio v2025-12 + LLVM v21.1.1
